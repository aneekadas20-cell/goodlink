Algorithmic Data Structures Lab

Inspect the internal memory architecture, pointers, and algorithmic invariants

🌳

NgoBST (Binary Search Tree)

Keyed by integer NGO ID • $O(\log n)$ Search
5 Nodes

Ensures that NGOs are automatically kept ordered. In-order traversal (Left → Node → Right) prints NGOs in strictly ascending ID sequence for the Telegram NGOS command.

📦

ActivityArray (Dynamic Array)

Primitive Activity[] with $2\times$ Geometric Expansion
5 Elements

Pre-allocates memory slots. When capacity is reached, it automatically re-allocates a new array with double capacity and copies existing pointers, providing $O(1)$ amortized additions.

🚨

UrgentRequests (Dual Priority Queue)

Strict Invariant: Urgent Queue ALWAYS Serviced Before Normal
Priority System

Maintains two discrete FIFO queues (urgentQueue and normalQueue). Calls to dequeue() strictly drain the urgent queue first before touching normal requests.

🔴 Urgent Queue (Highest Priority)
No urgent emergency requests
🟡 Normal Queue (Standard FIFO)
No standard requests queued
🎁

MyQueue<Donation> (FIFO Queue)

Front & Rear Node Pointers • Sequential Goods Allocation
FIFO Store

Singly linked queue nodes with $O(1)$ enqueue at tail and $O(1)$ dequeue at head. Guarantees fair, chronologically ordered distribution of pledged blankets, ration kits, and supplies.

🏆

MyLinkedList<Achievement> (Prepend List)

addFirst() • Newest Milestones Rendered First
Newest First

Every time a volunteer completes an activity, an achievement node is prepended via addFirst(), ensuring $O(1)$ insertions and immediate visibility at the top of the wall.

🌳

CategoryTree (General N-ary Tree)

Recursive Taxonomy Node Graph
N-ary Graph

Hierarchical domain model connecting broad charity sectors to granular operational domains (e.g., Elder Care → Dementia Care, Child Welfare → Orphanages).
